# Game music

Drop MP3 files here. Every MP3 in this folder is a game track: one is picked at random when a
game starts, and another random one (never the same twice in a row) follows when it ends.
Players can pause or skip from the game's top bar, and turn music off or set the volume in
Settings → Music.

Tips: about 2½–4 minutes per track, 96–128 kbps, no silence at the start or end. The tracks are
downloaded in the background after the first visit so they play offline.
